# Third-Party Notices — Arduino

This combined tree includes third-party Arduino libraries and Nick Gammon's I2C scanner.

### Sketches
- `I2CScanner` — Nick Gammon (2011).
- Other sketches — Dave Robinson / VaderConsulting.

### Libraries (working copies)
- `Adafruit_BusIO` — Adafruit: This is a library for abstracting away UART, I2C and SPI interfacing
- `Adafruit_Circuit_Playground` — Adafruit: All in one library to control Adafruit's Circuit Playground board.
- `Adafruit_GFX_Library` — Adafruit: Adafruit GFX graphics core library, this is the 'core' class that all our other graphics libraries derive from.
- `Adafruit_GPS_Library` — Adafruit: An interrupt-based GPS library for no-parsing-required use
- `Adafruit_HMC5883_Unified` — Adafruit: Adafruit HMC5883L 3-Axis Magnetometer Breakout library using Adafruit's Unified Sensor Library.
- `Adafruit_ILI9341` — Adafruit: Library for Adafruit ILI9341 displays
- `Adafruit_LED_Backpack_Library` — Adafruit: Adafruit LED Backpack Library for our 8x8 matrix and 7-segment LED backpacks
- `Adafruit_SSD1306` — Adafruit: SSD1306 oled driver library for monochrome 128x64 and 128x32 displays
- `Adafruit_STMPE610` — Adafruit: Arduino library for STMPE610/811 resistive touch screen controllers
- `Adafruit_SleepyDog_Library` — Adafruit: Arduino library to use the watchdog timer for system reset and low power sleep.
- `Adafruit_TouchScreen` — Adafruit: Adafruit TouchScreen display library.
- `Adafruit_Unified_Sensor` — Adafruit <info@adafruit.com>: Required for all Adafruit Unified Sensor based libraries.
- `Adafruit_Zero_DMA_Library` — Adafruit: DMA helper/wrapped for ATSAMD21 such as Arduino Zero & Feather M0
- `Adafruit_Zero_FFT_Library` — Adafruit: FFT library for Arduino Zero / Adafruit Feather M0 (SAMD21 processor).
- `Adafruit_Zero_PDM_Library` — Adafruit: PDM Microphone Input library for Arduino Zero / Adafruit Feather M0 (SAMD21 processor).
- `AltSoftSerial` — Paul Stoffregen: Software emulated serial using hardware timers for improved compatibility
- `ESP8266_Microgear` — Chavee Issariyapat <i@chavee.com>: A client library for ESP8266 to connect to NETPIE IOT Platform.
- `Encoder` — Paul Stoffregen: Counts quadrature pulses from rotary & linear position encoders.
- `Keyboard` — Arduino: Allows an Arduino board with USB capabilities to act as a Keyboard.
- `MFRC522` — GithubCommunity: Arduino RFID Library for MFRC522 (SPI)
- `MsTimer2` — Javier Valencia: Run an interrupt function using Timer2
- `Notched_Shaft_Encoder` — Lester Lo: Monitor the postion and clickable button status from a Notched Shaft Encoder
- `RTClib` — Adafruit: A fork of Jeelab's fantastic RTC library
- `SafeString` — Matthew Ford: A Safe, Static String library to replace Arduino String, plus non-blocking Serial I/O, I/O buffering, loopTimer and millisDelay
- `SerialFlash` — Paul Stoffregen: Access SPI Serial Flash memory with filesystem-like functions
- `SevenSegmentTM1637` — Bram Harmsen <bramharmsen@gmail.com>: Library for using a 4 digit seven segment display with TM1636 or TM1637 driver IC
- `SparkFun_HyperDisplay` — SparkFun Electronics <techsupport@sparkfun.com>: Standardized library for control of displays
- `SparkFun_HyperDisplay_ILI9163C` — SparkFun Electronics <techsupport@sparkfun.com>: ILI9163C extension for HyperDisplay
- `TM1637TinyDisplay` — Jason Cox <jason@jasonacox.com>: A simple library to display numbers, text and animation on 4 and 6 digit 7-segment TM1637 based display modules.
- `TinyWireM` — Adafruit: I2C library for Trinket and Gemma, adapted from BroHogan's code on Arduino Playground
- `WaveHC` — William Greiman: WaveHC wave shield library
- `arduino_644462` — Seeed Studio: Arduino library to control Grove_4Digital_Display TM1637.

VaderConsulting / Dave Robinson did not author the third-party library code.
